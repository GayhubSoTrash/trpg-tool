## 2.3.0：即時聊天室與基礎戰技

本版只處理本機功能，不處理公開部署；公開網址與主機可交給其他人處理。

### 右側聊天室
- 「戰鬥」：主聊天室，顯示戰技、擲骰、傷害與救援結果
- 「隊伍」：副聊天室，可選擇玩家角色作為聊天 ID
- Socket.IO 即時同步：同一台主機上的多個瀏覽器會立即收到訊息

### 初始戰技
依規則表目前先實作：
- 基礎攻擊：1AP、【1.0物理】、選敵方、1D100 命中 / 暴擊判定
- 救援：1AP、【蓄力1】、只選 HP=0 友方、不擲骰

### 基礎攻擊公式
- 命中：1D100 <= 自身命中 - 目標迴避
- 暴擊：命中後，同一個 1D100 <= 自身暴擊率
- 基礎暴擊傷害：50%
- 物理基礎傷害：物理攻擊 × 1.0
- 最終傷害：floor(傷害 × (1-格擋率) × (1+增減傷) × (1+暴擊傷害) - 防禦)
- 最低傷害 1
- 目前角色資料還沒有格擋率，所以格擋率先以 0% 計算

現有 Buff 會參與計算：
- 進攻指令：攻擊力 +25%
- 戰吼：傷害 +25%
- 防禦姿態：防禦力 +25%

### 救援
按下後不擲骰，先消耗 1AP 並建立「蓄力1」。
當該角色下一次成為當前回合角色時，救援會自動完成，若目標仍 HP=0 則恢復到 1HP。

## 2.9.0 — 格擋率、Buff 公式與目標限制

### 角色建立 / 角色卡
- 建立角色時，HP 保留在最上方與 AP / SP 同區，可直接輸入；角色卡下方重複的「生命」欄已移除。
- 新增「格擋率」屬性，建立角色與角色卡都可以直接輸入。
- 格擋率基礎值預設 0%，實際有效值上限固定 75%。
- 受到 Buff 影響的物攻、魔攻、命中、迴避、速度、防禦、魔抗與格擋率，在角色卡欄位上會標示 Buff 後有效值。

### 主戰鬥面板
- 戰技操作者改成和隊伍聊天室角色選擇器相同的簡潔身份列：頭像、名字、AP/SP、點擊切換。
- 移除原先佔空間的大型角色展開選單樣式。

### 目標限制
- ATTACK：只允許選擇仍可受攻擊的敵方。
- DEBUFF：只允許選擇敵方。
- HEAL：只允許自己陣營；「其他友方」會排除自己。
- ALLY_DOWN：只列出 HP <= 0 的其他友方。
- SELF / ALLY / ALLY_ROW / ALL_ALLIES / ENEMY / ENEMY_ROW / ALL_ENEMIES 都有前後端雙重驗證。
- 目前敵方一排 / 全體攻擊仍以所選敵方作為技能目標入口；不會誤選友方。完整多目標傷害結算會再逐技補齊。

### 格擋
依規則表實作：
- 只有物理傷害能被格擋；魔法傷害不能格擋。
- 被格擋的物理攻擊不能暴擊。
- 有「基礎格擋」或「自動格擋」時，物理攻擊會使用角色有效格擋率。
- 格擋率最高 75%。
- 傷害順序為：基礎傷害 × (1-格擋率) × (1+所有增減傷) × (1+暴擊傷害) - 防禦/魔抗；向下取整，最低 1。
- 「所有增減傷」使用同一加總項，例如造成傷害 +25% 與受到傷害 -25% 會互相抵銷，不以 1.25×0.75 複利計算。

### 已接入公式 / 狀態的 Buff
- 進攻指令：物攻、魔攻 +25%。
- 戰吼：同排友方造成傷害 +25%。
- 加速：命中 +20、迴避 +20、速度 +10，可疊加。
- 進攻架勢：物攻 +25%，並依原技能回復 AP。
- 戰爭號角：本輪攻擊無法被格擋。
- 嘲諷：速度 -10。
- 堅守：防禦 +25%、格擋率 +25%，可疊加。
- 震怒：造成傷害 +25%、命中 +25，可疊加。
- 防守姿態：防禦 +25%，並依原技能回復 SP。
- 鋼鐵帷幕：其他友方格擋率 +50%。
- 戰線保衛：同排其他友方防禦 +50%。
- 防護指令：全友方防禦、魔抗 +50%。
- 狙擊指令：全友方命中 +30。
- 飛速指令：全友方速度 +10，會參與回合排序。
- 格擋指令 / 自動格擋：物理攻擊自動依格擋率結算。
- 障壁：下一次受到的傷害 -25%，實際使 HP 受傷後消耗。
- 生命護盾：先扣自身 HP 產生護盾；受傷時先扣護盾，護盾破裂後才扣 HP。
- 賦能：下一次物理近戰攻擊每一命中段附加【0.5魔法】，使用後消耗。
- 鋒銳：下一次攻擊命中施加流血，使用後消耗。
- 破陣：下一次攻擊無法格擋；命中後施加格擋封印。
- 束縛 / 格擋封印：目標無法格擋。
- 熠光連結：施術者魔攻 -50%，目標獲得施術者因此失去的魔攻。
- 隨風而行：指定友方速度 +10。
- 快速詠唱：本輪行動順序優先（「僅限一次」的消耗時點之後再補）。

### 僅顯示狀態、尚不虛構數值的 Buff
規則表目前只給了狀態名稱、沒有數值定義，因此目前只忠實顯示，不自行發明：
- 再生
- 疾行
- 庇護
- 幻影
- 流血的持續傷害數值

### 已補強的恢復
- 治療 / 快速治療 / 戰線治療依技能倍率與魔法攻擊計算。
- 救援 / 復甦只針對被擊倒友方。
- 同生會扣施術者 50% 當前 HP 並將實際量恢復給其他友方。
- 共享恢復會同時解除目標目前已建模的減益。

## 2.10.0 — 狀態效果與攻擊範圍

### 狀態效果
本版把下列狀態接入角色 Buff / Debuff 圖標與戰鬥計算：

- 疾行：下一次基礎移動消耗 -1；直接拖曳移動時若原本消耗 1SP，改為 0SP，之後消耗疾行。
- 再生：持有者每次發動主動戰技時，恢復施加者有效魔法攻擊 × 0.75 的 HP。
- 庇護：下一次收到的一組減益無效，之後消耗庇護。
- 幻影：下一次原本會命中的攻擊段改為未命中，之後消耗幻影。
- 暈厥：【抗性】下一個回合自動跳過。
- 假死：若角色被擊倒，下一個回合開始時恢復到 1HP。
- 流血：每一個實際命中的攻擊段，額外損失施加者有效魔法攻擊 × 0.5 的 HP。
- 黑暗：【抗性】下一個攻擊段強制未命中。
- 中毒：每次進行主要行動時，損失施加者有效魔法攻擊 × 0.5 的 HP。
- 格擋封印：無法進行格擋。
- 燃燒：每次進行輔助行動時，損失施加者有效魔法攻擊 × 0.5 的 HP。
- 冰凍：【抗性】迴避視為無法使用，且不能發動輔助戰技；在下一回合開始或真正受到 HP 傷害時解除。
- 嘲諷：下一次主要行動若施加者仍是可攻擊敵方，必須使用攻擊戰技且攻擊範圍必須包含施加者。
- 狂暴：【抗性】下一個會致死的「傷害段」改為 0；只消耗該段，後續多段攻擊仍照常結算。
- 死鬥：【抗性】狀態存在時 HP 不低於 1。死鬥技能在狀態於輪結束時消失時，若指定敵人仍未擊倒，自己 HP 降至 0。

【抗性】使用 status_resistances 記錄；同一個抗性狀態在同一場戰鬥只會對同一角色生效一次，重置戰鬥時清空。

### 明確數值 Buff / Debuff
下列數值效果不再只是聊天室文字，會以狀態圖標顯示並實際改算式：
- 猛擊 / 輪擺 / 戰線剋星命中：防禦 -25%
- 螺旋劍：目標迴避 -20、自身迴避 +20
- 視線轉移：目標迴避 -50%
- 疾風箭：目標迴避 -50
- 挑釁：額外行動速度 -10
- 暗影噬咬命中：額外行動速度 -10
- 原本的進攻指令、防護指令、狙擊指令、飛速指令、戰吼、堅守、震怒等仍直接參與有效能力與傷害公式。

### 攻擊範圍
戰技描述中的範圍不再全部視為單體：
- 橫排：以 row_index 為同一橫排，選一名角色作為該排錨點。
- 順劈：選中目標 + 同橫排一名相鄰敵人，最多兩名。
- 迴旋擊 / 魔技賦予 / 輪擺 / 戰線剋星 / 暗影噬咬：同一橫排所有符合條件敵人。
- 長槍突刺：選中目標 + 同一列前 / 後相鄰敵人，最多兩名。
- 廣域猛擊：所有存活敵方。
- 雷霆劍：依施術者所在欄位，攻擊所選敵方戰場中「正前方同一列」的敵人。
- 魂靈風息：若施術者與方向錨點在同一格群，依前 / 後 / 左 / 右直線展開；同陣營角色恢復、敵方角色受攻擊。

### 圖標
暈厥、假死、流血、黑暗、中毒、燃燒、冰凍、狂暴、死鬥、防禦降低、迴避升降、速度降低等皆加入獨立小圖標。
滑鼠停留會顯示「增益 / 減益 / 特殊狀態」、名稱、完整效果、疊層 / 數值與期限。

## 2.12.0 — 反應時點 / 插入戰技系統

### 一般戰技清單
已支援的「條件反應戰技」不再平常出現在主戰技清單裡。
只有符合時點、角色真的有攜帶該戰技、且 AP/SP 足夠時，才會出現在右側「反應時點」面板。

### 攻擊指定時
攻擊不會立刻結算。若有可用反應：
1. 主聊天室先宣言「A 使用某攻擊指定 B」。
2. 右側出現所有目前可用反應。
3. 使用其中一個反應，或按「放棄反應，繼續受擊」。
4. 原攻擊才繼續進入擲骰與傷害。

目前已自動化：
- 守護：代受 + 格擋
- 奉獻：代受；本次自身防禦 / 魔抗視為 0；SP+1
- 快速移位：與被指定友方交換位置並代受
- 障壁：原目標下一次受到傷害 -25%
- 偏斜：本次格擋，攻擊者獲得易傷
- 撥擋：一段攻擊傷害無效，AP+1
- 箭擊掩護：指定友方本次遠程物理攻擊傷害無效
- 重擊聲援：本次暴擊率 +50%
- 破陣：本次無法格擋，命中時施加格擋封印
- 精準打擊：本次暴擊傷害 +50%
- 鋒銳：本次命中施加流血
- 獵鷹之眼：本次遠程攻擊無法迴避
- 光導：本次攻擊無法迴避、無法暴擊

### 戰技結算後
同一個時點的所有可用反應會一次列在同一面板，不會逐個跳確認框。

目前已自動化：
- 快速治療：友方受到 HP 傷害後，恢復【0.75魔法】
- 預後：自身造成實際治療後，可將每名目標實際治療量的 50% 加成護盾
- 重燃：其他友方剛消耗 SP 發動戰技後，使該友方 SP+1
- 堅守：自身受到物理 HP 傷害後，本輪防禦 +25%、格擋率 +25%，可疊加
- 震怒：其他友方受到 HP 傷害時，本輪自身傷害 +25%、命中 +25，可疊加
- 沉重反擊：自身受到攻擊後，以【0.5物理】反擊攻擊者
- 城墻反擊：自身受到攻擊且 HP 傷害低於 1 時，使攻擊者損失自身有效防禦等量 HP

### 可攜帶戰技判斷
反應選項只從 `character_skills` 讀取。
角色沒有裝進可攜帶戰技槽的戰技，不會出現在反應面板。
